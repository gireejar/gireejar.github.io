# Website workflow notes for agents

- The live site is https://gireejar.github.io, built from `sites/franklin` by
  `.github/workflows/deploy.yml` on every push to `main`.
- **Never `git push` (or trigger the deploy workflow) unless the user explicitly
  asks to deploy / go live.** Batch changes locally: edit, build and preview
  locally, and commit only when asked. Pushing = publishing.
- Local preview: `python3 tools/build_sites.py`, then in `sites/franklin`:
  `julia -e 'using Pkg; Pkg.activate("."); Pkg.instantiate(); using Franklin; serve()'`
- Pages generated by `tools/build_sites.py` (index, papers, teaching, group,
  media, outreach, miscellaneous, updates) come from `data/`; edit the data
  files or the generator, not the generated `.md` files.
